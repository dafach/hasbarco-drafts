## How to update

1. Edit HTML/assets in this repo (or sync from the cleaned `hasbarco-sb` source of truth).
2. Commit and push to `main`.
3. GitHub Pages redeploys from `main` / root automatically.

Lang switchers use relative links (`index.html` / `index-es.html`) so they work under the `/hasbarco-drafts/<property>/` path.
